# v14 sources — Solo's optimizations

New optimizations by Solo and his Opus/Fable team, based on nosty/Astra v11. Sources and build tools are preserved here. Use the repository-level scripts/rebuild_current.py to reconstruct the v11 base and build v14 in ignored build/. See ../../docs/REBUILD.md. AGENT.md is the upstream technical handoff; its package-local fixture paths refer to the original delivery, not all of which is included here. Performance observations are in ../../results/v14. This source package does not supply a v14 XEX.
